# テクスチャビューアー

Windows版は共通の `build/vs2026/flycast.slnx` からビルドします。
`shell/windows/generate_vs_project.bat --run` を実行すると、最新のソースをビルドしてから
`build/vs2026/Release/flycast.exe` を起動します。テクスチャビューアー専用のソリューションはありません。

「設定 → ビデオ → テクスチャビューアーを表示」をオンにすると、ゲーム実行中に
読み込まれたテクスチャを確認できます。
Windowsデスクトップ版では、ゲーム画面とは別のウィンドウに表示されます。
ゲーム中のメニューの「テクスチャ」からも切り替えられます。
設定を保存しておくと、次回の起動時も有効です。

- タイトルバーをドラッグして移動、ウィンドウの端をドラッグしてサイズ変更できます。
  別のモニターにも移動できます。移動・サイズ変更中もゲームは動き続けます。
- サムネイルをクリックすると、拡大画像、サイズ、形式、VRAMアドレスが表示されます。
  「戻る」で一覧に戻ります。拡大画像はクリックした時点のプレビューです。
- 「フィルター」でアドレス・サイズ・形式を絞り込み、左右の矢印でページを切り替えます。
- 右上の × でビューアーだけを閉じられます。ゲームは終了しません。
  メニューの「テクスチャ」をオンにすると再表示できます。
- ゲームのメニューや設定を開いている間も表示され、ゲームを終了すると閉じます。
- 一時停止中に初めて有効にした場合は、一度ゲームを再開すると画像が収集されます。

ウィンドウ上部にVRAM使用量の目安を表示します。

- **VRAM使用量（テクスチャ推定）**: 現在有効なテクスチャキャッシュが参照する
  VRAM領域と、機種の総容量です。Dreamcastの総容量は8 MiB（8,388,608バイト）です。
  アドレスが重なるテクスチャやパレット違いは重複計上せず、VQ圧縮のコードブックと
  ミップマップも含めます。PC側での拡大画像やカスタムテクスチャの画像サイズは加算しません。
- **最大（表示開始後）**: 今回の計測中に記録したテクスチャ使用量の最大値です。
  ビューアーを閉じるかゲームを終了するとリセットします。描画APIの再初期化時もリセットします。
- **残り（上限）**: 総容量から上記使用量を引いた値です。描画バッファ、描画命令、
  GPUだけで保持されているレンダーターゲット、ゲームが確保済みでまだ参照していない領域は
  未計測のため、その全量を追加テクスチャに使えるわけではありません。
  また、連続した空き領域やゲーム側のVRAM割り当ても判定できません。

計測対象はビューアー表示後に読み込まれ、まだVRAMの書き換えで無効化されていない
テクスチャです。現在の画面に見えているものだけには限定しません。
フィルター、ページ、サムネイル512枚の表示上限は使用量に影響しません。
ゲーム側の正確な空き容量は、そのゲームのメモリ管理側で確認する必要があります。

Windowsデスクトップ版以外では従来どおりゲーム画面上のパネルに表示します。
こちらはマウスを重ねて拡大表示し、メニューや設定を開いている間はパネルが隠れます。

OpenGL・Vulkan・Direct3Dで共通の読み込み処理から、最大512枚のサムネイルを保持します。
サムネイルは長辺128ピクセル以下で、ゲームのテクスチャサイズは元の読み込みサイズを表示します。
カスタムテクスチャは差し替え後の画像を表示します。
上限に達すると更新の古い画像から除外され、ゲーム終了時や非表示にしたときに収集データを解放します。

一覧は現在のキャッシュの読み込み画像です。画面内で使用されているものだけには限定しません。
GPU上で直接描画されるレンダーターゲットは対象外です。
有効にするとプレビュー作成とパレット変換の処理が増えるため、必要なときだけ有効にしてください。
